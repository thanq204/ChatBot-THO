# Câu hỏi member

Lưu câu hỏi mới của member trước khi chuẩn hóa và gom nhóm trùng lặp.

Dùng một file JSONL riêng cho mỗi nền tảng. Các field tối thiểu:

```json
{
  "question_id": "Q-20260812-0001",
  "message_id": "MSG-123",
  "platform": "discord",
  "author_id": "member-456",
  "question": "Câu hỏi gốc",
  "created_at": "2026-08-12T10:30:00Z",
  "status": "new"
}
```
