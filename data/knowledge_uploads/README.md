# Kho upload knowledge hiện tại

Đây là kho upload đang được ứng dụng quản lý. Thư mục được giữ nguyên để tương thích với backend hiện tại.

Không đổi tên hoặc di chuyển thư mục này trong đợt tổ chức lại data. Code ingestion mới phải theo `RULES.md`; việc chuyển kho này sang `10_raw/uploaded_documents/` cần một task riêng từ team owner.
